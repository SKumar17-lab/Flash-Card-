# Flash-Card- App - CodeAlpha

A Simple Flashcard Learning App built with Flutter.

## Features
- Show Question and Answer
- Show/Hide Answer with button
- Next / Previous navigation
- Add New Card
- Edit & Delete Card

## Tech Stack
Flutter & Dart

## How to Run
flutter pub get
flutter run
